# DeepSeek Terminal AI Agent

A full-featured terminal AI agent powered by DeepSeek V4 Pro/Flash.  
Supports file read/write, shell commands, directory listing, and deep reasoning (1M context).

## Features

- 🧠 DeepSeek V4 Pro / Flash with reasoning effort control (`max` or `high`)
- 📂 Read, write, and list files
- 💻 Execute shell commands securely
- 🔄 Automatic multi-step tool calling
- 💾 1M token context window
- 🎨 Colored terminal UI
